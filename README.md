# Bahrom 3D Portfolio V9

Interactive 3D software engineering portfolio built with HTML, CSS, JavaScript and Three.js.

## Features
- 3D workstation, clickable project monitors
- Xabar, NurLevel and Fastpay project panels
- Orbit and WASD walk camera modes
- Day/night lighting, quality settings, responsive interface

## Run locally

```bash
python -m http.server 8000
```

Open http://localhost:8000.

## Project files

`index.html`, `style.css`, and `main.js` need to be uploaded from the V9 project archive.

Three.js is loaded from a CDN; internet access is required for the 3D engine.
